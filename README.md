# claude-switchboard

A keyboard-driven picker for live Claude Code agents.

`switchboard` lists every Claude Code session running on this machine - status,
name, working directory, age, and a one-line summary of what it is doing - and
jumps focus to the terminal window running the one you pick.

See [issue #1](https://github.com/adamsilverstein/claude-switchboard/issues/1)
for the full design.
